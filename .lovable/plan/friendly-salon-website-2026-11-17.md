# FRIENDLY SALON website

Build the salon’s complete public website at `/` as a responsive, editorial one-page experience.

## Work
- Establish an ivory, blush, champagne, and espresso design system with serif display type, accessible contrast, and subtle reduced-motion-aware animations.
- Create an elegant sticky navigation, photographic introduction, studio story, service menu, filterable nail gallery, studio values, editable review placeholders, booking form, contact details/map placeholder, and footer.
- Make booking validation clear; create a prefilled WhatsApp request and state that the appointment is pending salon confirmation. Keep unspecified contact, location, prices, social links, and review content visibly editable rather than inventing them.
- Add unique page metadata, preserve the supplied visual/business constraints, and keep the page’s content easily maintainable.

## Technical details
- Implement with the existing TanStack Start, React, Tailwind v4, and shadcn Button patterns; use GSAP/ScrollTrigger for restrained animation and the generated project photography.
- Test the home route, booking validation/WhatsApp request, and gallery filtering where practical; verify the preview and current build signals before committing.
